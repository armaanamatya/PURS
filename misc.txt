  Near-universal (4/5):
  - question by exact name — all except Daily-Omni (uses Question, 
  capitalized)
  - answer by exact name — all except OmniVideoBench (uses
  correct_option)
  - options by exact name — Video-MME, OmniVideoBench,
  ShortVid-Bench (3/5); WorldSense calls it candidates, Daily-Omni 
  calls it Choice

  Summary: Every dataset is a video-grounded multiple-choice QA    
  benchmark, so the four functional columns — video reference,     
  question, choices, and correct answer — are universal. The       
  task/category column is also present in all five but with highly 
  varied names and taxonomies.
